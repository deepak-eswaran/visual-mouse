# 3D Asset Credits

The non-hammer gallery objects are GLB assets hosted by Innerscene's Free Parts Library. Each source page currently labels its model CC0/public domain. The website loads these models directly at runtime to keep the GitHub repository small.

The Stormforged Hammer is an original procedural Norse-inspired concept made from Three.js geometry for this project.

The source library states CC0/public-domain reuse, including commercial reuse, on the pages above. The source URLs are external dependencies and may change or become unavailable. To vendor the assets locally in a future version, download the GLB files from their source pages and place them under `showroom/public/models/`, then update the model URLs in `showroom/src/app.js`.
